## Problems Covered

### Problem A — Recipe Inheritance

A `Recipe` class is created with `name` and `cookingTimeMinutes` attributes and a constructor.

A subclass `VeganRecipe` extends `Recipe` and adds an `ingredientList` attribute. The `display()` method is overridden to display all recipe details.

### Problem B — Cookable Interface

A `Cookable` interface is created with the `cook()` method.

The `BakedDish` class implements the `Cookable` interface and provides the implementation of the `cook()` method.

### Problem C — Exception Handling

A Java program is created to read a recipe file.

`FileNotFoundException` is handled using a `try-catch` block when the recipe file does not exist.

## Files

* `ProblemA.java` — Recipe inheritance and method overriding
* `ProblemB.java` — Cookable interface implementation
* `ProblemC.java` — FileNotFoundException handling
